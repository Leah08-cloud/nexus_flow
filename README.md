
Nexus Flow
Nexus Flow is a mobile application project focused on monitoring network stability, tracking real-time connectivity state changes, and maintaining uninterrupted data sessions to mitigate network disruptions.

Key Features
Real-Time Connectivity Monitoring: Dynamic state detection for Wi-Fi and mobile data networks.

Cross-Platform Architecture: Built with Flutter for mobile and desktop deployment.

Responsive Control Dashboard: Clean UI displaying real-time connection status and metrics.

Tech Stack
Framework: Flutter / Dart

State & Connectivity: connectivity_plus

Build Target: Mobile & Linux Desktop

Getting Started
Clone the repository:
git clone https://github.com/Leah08-cloud/nexus_flow.git
cd nexus_flow

Install dependencies:
flutter pub get

Run the application:
flutter run
